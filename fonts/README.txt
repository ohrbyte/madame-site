MADAME — FONT INSTALL
=====================

The titles use two Adobe-synced fonts: Neulis Sans and Neulis Cursive.
They can't be downloaded automatically, so drop the font files into THIS
folder and the whole site picks them up — no other edits needed.

Use these exact file names (any one of .woff2 / .woff / .otf / .ttf works;
.woff2 is smallest and best for the web):

  NeulisSans-Regular.(woff2|otf|ttf)
  NeulisSans-Medium.(woff2|otf|ttf)
  NeulisSans-SemiBold.(woff2|otf|ttf)
  NeulisSans-Bold.(woff2|otf|ttf)
  NeulisSans-ExtraBold.(woff2|otf|ttf)
  NeulisCursive-Regular.(woff2|otf|ttf)

Only have a couple of weights? Just add those — the page will use the
closest available weight for the rest.

Tip: to convert .otf/.ttf to .woff2 (smaller, faster), use
https://transfonter.org or the `woff2_compress` tool.

Until the files are here, the site falls back to a close system stack so
the layout and animations still look right.
